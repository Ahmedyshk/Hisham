# دفرنة في القدرات والتحصيلي — موقع مستر هشام خليل

موقع ثابت بالكامل لـ **مستر هشام خليل** — مدرب قدرات كمي، ومدرب معتمد من **المركز العربي
للتدريب والتنمية البشرية** — يجمع نماذجه الإلكترونية (Google Forms) في صفحة واحدة، مع بحث
فوري بالرقم أو بالاسم، وتصفية، ومتابعة تقدّم محفوظة على جهاز الطالب، ويمكن تثبيته كتطبيق على
الجوال والكمبيوتر.

والآية الكريمة ﴿يُرِيدُ اللَّهُ بِكُمُ الْيُسْرَ وَلَا يُرِيدُ بِكُمُ الْعُسْرَ﴾ تظهر في كل صفحة:
شريط أعلى الصفحة، ولوحة في الواجهة، وشريط عريض بين الأقسام، وفي التذييل.

**لا يوجد خادم، ولا قاعدة بيانات، ولا عملية بناء مطلوبة للنشر.** الملفات المرفوعة هي الموقع نفسه.

---

## Quick start

```bash
npm start           # preview at http://127.0.0.1:4173 (PORT=5177 npm start to change)
npm run verify      # rebuild data + run every test + validate the links
```

Nothing to install — every script is plain Node (>= 18) with zero dependencies. The image
pipeline (`tools/build-photos.py`) is the one exception; it is Python and only runs when the
logo or the photo changes.

## Adding the Google Form links (the next step)

Right now **no forms are published**, and that is a supported state: the home page shows a
«النماذج الإلكترونية تُضاف قريبًا» notice with WhatsApp and call buttons instead of the search
box, the stats and the grid. Everything else — the teacher page, the about page, SEO, the app
install — is complete.

To publish the forms:

1. Replace `data/source/forms.json` with the export. Either shape works:

   ```json
   {
     "المشروع": "دفرنة في القدرات والتحصيلي",
     "الفورمات": [
       { "النموذج": 1, "الاسم": "النموذج الأول", "عدد الأسئلة": 24,
         "الرابط المختصر": "https://forms.gle/…",
         "الرابط الكامل": "https://docs.google.com/forms/d/e/…/viewform" }
     ]
   }
   ```

   or English keys (`forms`, `section`/`number`, `title`, `questions`, `short`, `url`), or a
   bare array of forms. Only the number and the link are required: a form with no title is
   named «النموذج الحادي عشر» automatically, which the search finds by word or by number.
2. `npm run verify`
3. Publish (commit and push — the GitHub Actions workflow redeploys).

The build validates every row and **leaves out** anything with a bad number, a non-https link,
a duplicate number or a duplicate link, listing it in `data/build-report.json`. It then writes
the real state into `index.html` (search, stats, tiles and grid visible; the notice hidden), so
the first paint is already correct.

**Never put an *edit* link (`…/forms/d/<id>/edit`) in the export** — it gives anyone write
access to the live form. The build refuses to run if it finds one.

### Optional: a «ابدأ بهذه» shortlist

Put the numbers the teacher wants students to start with in `data/source/priority.json`:

```json
{ "label": "ابدأ بهذه", "blurb": "النماذج التي يبدأ بها المستر مع طلابه", "sections": [1, 2, 5] }
```

and run `npm run build:data`. A hero figure, a quick-access tile, a filter toggle, a card badge,
a second progress bar and a `?key=1` link all appear; delete the file and they all disappear.

## How it is put together

```
index.html              home: hero + verse plaque, search, quick access, forms grid, verse band, the teacher
teacher.html            مستر هشام خليل — profile, credentials, contact, FAQ (Person / ProfilePage / FAQPage)
about.html              عن المنصة — how to use it, installing it as an app, FAQ
404.html                fully self-contained (no external CSS/JS/images)
sw.js                   service worker — network first, cache as the offline fallback
site.webmanifest        the installable app (name, icons, shortcuts)
llms.txt / sitemap.xml  GENERATED by tools/build-data.mjs

assets/css/tokens.css      palette sampled from the emblem, type scale, spacing, dark theme
assets/css/base.css        font faces, reset, typography, layout primitives, a11y
assets/css/components.css  buttons, header, hero, tiles, toolbar, cards, sheet, toast, footer…
assets/css/brand.css       the identity layer: the verse (strip, plaque, band, footer), graph
                           paper and math symbols, the emblem, "coming soon", app install
assets/js/app.js           state -> URL -> render; cards; filters; progress; coming-soon state
assets/js/search.js        Arabic-aware search (folding, ranking, typo tolerance, highlighting)
assets/js/store.js         device-local progress (localStorage, fully guarded)
assets/js/ui.js            theme toggle, mobile menu, install-as-app, service worker registration

data/source/            the export, the logo and the photo as delivered (NOT published —
                        the deploy workflow removes it from the artifact)
tools/build-data.mjs    export -> assets/data/exams.json, stamps index.html, llms.txt, sitemap
tools/build-photos.py   logo + photo -> assets/img (emblem cut-out, portraits, icons)
tools/test-*.mjs        search, progress store, SEO + identity tests (npm test)
tools/og-cover.template.html   source of assets/img/og-cover.jpg (the link-preview image)
```

## Identity

| Role | Light | Dark |
| --- | --- | --- |
| Navy — structure, text, the action colour | `#223e5b` (emblem), text `#1a3049` | page `#0c1a2b` |
| Gold — rings, completion, the verse | `#ba9a68` (emblem), text `#6e5020`–`#96733a` | `#dcc08f`, actions `#d2b07a` |
| Paper — the banners' graph paper | `#f6f2e9` / `#fffdf8` | `#132840` |
| Sky `#88adc3`, clay `#c57a43` | tiny accents only | |

- **Navy acts, gold marks, paper carries.** In the dark theme navy becomes the page, so gold
  takes the action role.
- Every text colour meets WCAG AA (4.5:1) against its own background in both themes.
- Typefaces: **IBM Plex Sans Arabic** for everything, **Lalezar** for the brand wordmark only
  (it echoes the emblem's lettering), **Amiri** for the verse only. All self-hosted and subset —
  see `tools/build-fonts.md`.
- The hero and page heads use the form banners' own ground: warm paper, a faint graph-paper
  grid and scattered math symbols (x√, π, ÷, △, ∫).

### The emblem

`data/source/brand/logo-source.jpg` was delivered as a JPEG with a grey-and-white checkerboard
*painted into it* (an image generator's "transparent" preview), so it has no real
transparency. `tools/build-photos.py` recognises the checkerboard by colour, turns the part
connected to the border into real transparency and the part enclosed by the rings into the
paper colour, and un-mixes the anti-aliased edge pixels so no grey fringe survives. The result
reads cleanly on cream and on navy.

### The photo

The circle portrait is cut out (rembg, `u2net_human_seg`) and placed on the emblem's navy,
because the wall behind him carries an ornament and a painting a tight circle would frame. The
arch keeps the photograph as it was taken.

## Mobile, desktop and "install as an app"

- Mobile-first layout, checked at 390 px and 1440 px; no horizontal scroll at any width.
- `site.webmanifest` + `sw.js` make it installable: Chrome/Edge/Samsung Internet (Android and
  desktop) show an «ثبّت الموقع كتطبيق» button in the header, the mobile menu and the footer;
  iOS Safari shows a two-step "Share → Add to Home Screen" hint instead. The buttons stay hidden
  wherever installing is impossible or already done.
- The service worker is network-first: online students always get the latest pages and form
  list; offline, the last copy they loaded still opens.

## Deploying to GitHub Pages

1. Push this folder to a GitHub repository.
2. **Settings → Pages → Source: GitHub Actions**, and **Settings → Actions → General →
   Workflow permissions → Read and write**.
3. Push to `main`. `.github/workflows/deploy.yml` rebuilds the data, runs every test, stamps
   the real URL into canonical/OG/sitemap/llms.txt, drops `data/source/` from the artifact, and
   deploys.

Deploying from a branch instead also works — run `npm run set-url -- https://your-site/` first
so the absolute URLs in the metadata are right.

## What the tests guard

`npm test` fails if any page: loses the verse (it must appear at least three times per page,
with the strip above the header), stops naming «مستر هشام خليل», «دفرنة في القدرات والتحصيلي» or
«المركز العربي للتدريب والتنمية البشرية», drops the WhatsApp/call links or either spelling of the
number, has FAQ markup that differs from the visible text, carries a structured-data `@id` that
does not resolve, has an `<img>` without dimensions, a `target="_blank"` without
`rel="noopener noreferrer"`, an unsupported claim (best / guaranteed / «معتمد من قياس» / prices
/ "free" / years of experience / student counts), or any trace of the site this one was modelled
on. It also checks the manifest, the icons, the service worker, the sitemap, robots.txt, and that
the build stamped the right data state into the home page.

## What only the owner can do

1. **Google Search Console** — verify, submit `sitemap.xml`, request indexing of `/teacher.html`.
2. **Bing Webmaster Tools** — import from Search Console (Bing feeds ChatGPT search and Copilot).
3. **A public profile** — when he has a page students already know (WhatsApp Business, a
   channel), add its URL as `sameAs` on the Person in `index.html` and `teacher.html`.
4. **A custom domain** — a stronger signal than a `github.io` path.
